# kata-castellers

Kata 82 per a especialitats web 8-10-26

Fa poc va ser el concurs internacional de Castellers! (i la prova de nivell d'un dels vostres companys!)

En honor a això, farem un programa que donat un **nombre de pisos**, i un **nombre de persones** per pis, dibuixi un [castellet](https://es.wikipedia.org/wiki/Castell) d'aquestes característique donades.

Podeu dibuixar-lo per terminal o amb HTML/CSS. 

**Bonus Track** Dibuixeu també la [pinya](https://ca.wikipedia.org/wiki/Pinya_(castell))  del castellet.  
**Bonus Track 2** Doneu opció a dibuixar també a dibuixar [folre](https://ca.wikipedia.org/wiki/Folre) i [manilles](https://ca.wikipedia.org/wiki/Manilles).
